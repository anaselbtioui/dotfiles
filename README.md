# dotfiles

Ubuntu 26.04. Reduce variation; do not add decoration.

Stock Yaru-dark. One Modus palette. GNOME is the daily session; Sway is a second GDM session.

```bash
./bootstrap.sh
sudo ./scripts/root-setup.sh           # packages + GDM
sudo ./scripts/root-setup.sh --sway    # optional Sway session
```

Log out once. [Design](docs/design-system.md) · [Why](docs/rationale.md) · [Sway](docs/sway-trial.md)
